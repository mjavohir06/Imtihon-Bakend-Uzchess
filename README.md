# UzChess — imtihon backend (Express)

O'quv kursi imtihoni uchun yasalgan UzChess platformasi backendi (2-versiya).
Frontend: [Imtihon-Uzchess-Frontend](https://github.com/mjavohir06/Imtihon-Uzchess-Frontend)

**Texnologiyalar:** Node.js, Express, TypeScript, TypeORM, PostgreSQL, JWT, Multer, Swagger

## Modullar
- `user` — foydalanuvchilar va avtorizatsiya
- `Kurslar` — kurslar
- `News` — yangiliklar
- `library` — kutubxona
- `file` — fayl yuklash

## Ishga tushirish

```bash
npm install
# .env fayl yarating: PostgreSQL ulanishi va JWT kalitlari
npm run dev
```
